# Observanda 0.3.0-alpha.1

**Alpha release for testing and feedback.** Observanda still needs broader testing, and some features and workflows are not fully implemented. Bugs and changes in behaviour should be expected. This is not a stable release.

## Included

Observanda brings together local writing, evidence, project and lab-book organization, revision history, scientific tools, collaboration, PDF layout and website publishing. See the [README](https://github.com/Seigr-lab/Observanda#readme) for an overview.

This release provides a Windows x64 installer with the application and its required runtimes. macOS and Linux installers are not included.

## Testing and limitations

- Testing across operating systems, storage devices and larger workloads remains incomplete.
- Some authoring and publishing features and workflows still need implementation or qualification.
- Commercial-print PDF/X qualification is unfinished; do not treat PDF/X conformance as established.
- Performance work remains, particularly for larger workloads on network storage.

Evaluate the Alpha using copies of important work and keep independent backups. Check exported documents and websites before sharing or publishing them.

## Download

- `Observanda-0.3.0-alpha.1-win-x64.exe`: Windows x64 installer.
- `SHA256SUMS.txt`: SHA-256 checksums for the installer and these release notes.

The Windows installer is not code signed. The supplied checksums let you check download integrity.
