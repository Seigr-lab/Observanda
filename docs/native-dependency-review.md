# Native dependency review: 27 October 2026

This is a partial review of current source pins. It is not a clean security bill for an installed or packaged release. Exact candidate inventories, all transitive native components and applicable advisory dispositions remain release requirements.

| Component | Reviewed state | Evidence and remaining boundary |
| --- | --- | --- |
| Electron | 44.9.3 | Current supported 44.x patch was verified from upstream releases. A source-runtime probe identifies Chromium 152.0.7977.167, embedded Node 24.22.0 and Undici 7.29.1. npm dependency updates do not patch embedded Undici. Its applicable advisory assessment remains open; updating to Electron 45.0.0 would still select Node 24.22.0 and would introduce unrelated breaking changes. |
| Standalone Node | 24.22.1 | Its pinned binary reports Undici 7.30.1. This is distinct from Electron's embedded Node. Each candidate must reproduce the runtime inventory. |
| PostgreSQL | 17.11 | The reviewed PostgreSQL 17 security table lists fixes through 17.11. This checks the selected server release, not arbitrary external servers or every library in a supplied native payload. |
| Windows Git | 2.56.0.windows.4 | Official MinGit SHA-256 pin includes the intermediate-CA mitigation from Windows.3 and Brotli 1.2.1 from Windows.4. Version admission rejects the old Windows payload. The tested helper uses this Git without changing global configuration. Supplied Ubuntu Git and its linked libraries require their own candidate review. |
| Git Credential Manager | 3.0.2 | Official archives and actual Windows/Ubuntu executables are checked. Native-AOT runtime provenance binds .NET 10.0.14 to those exact executables. Synthetic native credential-store checks pass on both platforms; see [credential runtime](credential-runtime.md). |
| FFmpeg | 9.0.2 pin | Upstream's security list records the 9.0 branch fixes. Each candidate still needs the exact FFmpeg configuration and linked/bundled codec library inventory; its version line alone does not establish that coverage. |
| PDF validation Java | 25.0.5+8 on Windows/Ubuntu x64 | Official October-patched Temurin 25 LTS archives are hash-pinned. veraPDF 1.30 added Java 25 support. Actual Windows/Ubuntu PDF/A-2u and PDF/UA validation, version admission and cancellation cleanup pass with the new runtime. Runtime/source manifests use each platform's own version; other platform pins are not qualified by these results. |
| veraPDF | 1.30.3 pin | The pinned JAR contains 20 Maven component identities, retained in the payload source manifest. An OSV exact-version query on 27 October returned no matching advisories for those identities, including Jackson 2.22.3 and JAXB 2.3.2. This is a dated advisory-database result, not proof of vulnerability absence or parser confinement. |

The Electron Undici findings include integrity-option handling and TLS-agent behaviors fixed in 7.30.1. An unreachable affected API may justify a reviewed, expiring exception, but an inventory or a search for direct calls does not establish transitive unreachability. No such exception is approved by this document. Remaining native-library inventories and exact candidate review are unresolved; do not mark the release dependency gate passed from this table.
